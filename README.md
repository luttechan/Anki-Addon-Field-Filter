# Periodic Auto Sync

Periodic Auto Sync adds configurable periodic AnkiWeb synchronization to
desktop Anki.

## Features

- Configurable sync interval
- Tools → Periodic Auto Sync → Sync Now
- Session-only Pause Auto Sync
- Optional additional startup sync
- GUI settings dialog
- Uses Anki's own normal Sync button workflow

## Default settings

- Enabled: yes
- Interval: 10 minutes
- Additional startup sync: no

## Platform

Desktop Anki only.
