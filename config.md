# Periodic Auto Sync Settings

Recommended configuration path:

**Tools → Periodic Auto Sync → Settings...**

- `enabled`: enable or disable periodic synchronization.
- `interval_minutes`: sync interval in minutes, from `1` to `1440`.
- `sync_on_start`: run an additional sync shortly after opening a profile.

`Pause Auto Sync` is temporary and lasts only for the current Anki session.
